# VertexBox Hardware

This is the hardware part of the little affordable robot, "VertexBot". This is a project in its early inception. Once the hardware is finalised, we will assemble a swarm of these little buggers (max 32 in a flock by design),  and test various things, and learn. The robots will have image processing and audio/DSP capabilities and will identify between themselves with the help of coloured lights.
